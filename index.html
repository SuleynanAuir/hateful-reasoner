From image–text alignment to contextual reasoning. HateReasoner combines global context, semantic guidance, and local graph relations to interpret what a meme implies.

Abstract

Hateful memes can convey harmful meaning through a combination of otherwise innocuous images and words. Sarcasm, stereotypes, and implicit accusations require reasoning beyond surface-level image–text similarity. HateReasoner investigates a framework built on CLIP representations with three complementary pathways. A Presupposed Context Module (PCM) captures interactions between global image and text embeddings. A Semantic Guidance Module (SGM) emphasizes relevant visual and linguistic cues through a semantic prior. A Graph-based Multimodal Module (GMM) links text tokens and image patches to support relational reasoning. The semantic and graph pathways form the Semantic-Context Fusion Module (SCFM); their features are combined with global context for binary classification. Original, masked, and inpainted image views provide different visual inputs. The available project materials describe the architecture and qualitative preprocessing examples; they do not provide numerical results for a verified performance comparison.

Presupposed Context & Guided Graph Reasoning

Represent the scene and its implied meaning. CLIP encoders produce global embeddings and local image-patch and text-token features. Lightweight projection heads map both modalities into a shared space. PCM applies modality-specific transformations to the global vectors and combines them through an element-wise product, hpc = fv(hv) ⊙ ft(ht). This captures how the image and caption jointly establish context.

Connect semantic cues across modalities. SGM uses a semantic prior to weight and update multimodal tokens. GMM constructs sequential text edges, spatial image-patch edges, and selected cross-modal links. Graph message passing aggregates these relationships into a relational representation. Context, semantic, and graph features are concatenated for classification, combining coarse scene-level interpretation with fine-grained evidence.

The project excerpts describe LLM guidance. The enhanced implementation obtains its prior from a text-embedding API and groups the semantic and graph pathways inside FACTModule; it does not execute the explicit false-claim prompt described in the manuscript.

Controlled evaluation should compare image views and module ablations on identical held-out splits, reporting AUROC, F1, and accuracy. The current enhanced training entry point also evaluates its test loader during training; a final benchmark protocol should reserve test data for independent evaluation.
