THE RESEARCH QUESTION

Abstract

Hateful memes can communicate through a relationship between image and text that neither modality expresses alone. Sarcasm, stereotypes, and implied accusations make this relationship difficult to capture through surface-level alignment. HateReasoner investigates a multimodal framework that combines global context with local, semantically guided reasoning.

A Presupposed Context Module (PCM) models interactions between global visual and textual representations. A Semantic-Context Fusion Module (SCFM) brings together a Semantic Guidance Module (SGM) and a Graph-based Multimodal Module (GMM): semantic guidance emphasizes relevant cues, while graph reasoning connects words and image regions. The resulting representations are fused for binary hateful meme classification.

This page presents the framework described in the supplied project excerpts alongside its research implementation. It includes the motivating examples, preprocessing strategy, architecture, and benchmark reference. Quantitative project results are not included in the supplied materials.

01 / REPRESENTATION

Separate global meaning from local evidence

The visual encoder produces a global image representation and patch-level features. The text encoder produces a global text representation and token-level features. Lightweight projection heads map them into a shared space, retaining broad semantic context alongside local evidence such as objects, negation, and group references.

02 / CONTEXT

Model what the pairing implies

PCM applies modality-specific transformations to global image and text vectors, then combines them through a Hadamard product. This explicitly represents their interaction: a caption can change how a scene is interpreted, while a scene can change what a sentence implies.

03 / GUIDANCE

Give relevant tokens more influence

SGM relates multimodal tokens to a semantic prior. Normalized similarity scores are converted into attention weights, used to update token representations and construct a pooled semantic feature. The project excerpt motivates this with language-model guidance about potentially false claims.

04 / RELATIONS

Connect words to visual regions

The graph contains intra-text, intra-image, and cross-modal edges. Sequential text neighbors and adjacent image patches preserve local structure; top-ranked cross-modal links connect relevant words and patches. Message passing produces a relational feature that complements global context.

How the released implementation maps to the project description

In new_engine_enhanced.py, the semantic and graph pathways are grouped in FACTModule, with methods named build_spm and build_crm_edges. The enhanced implementation uses text embeddings from an API as its semantic prior; it does not execute the explicit false-claim prompt described in the project excerpt. Two GNN layers aggregate the graph. Context, semantic, and graph features are concatenated before classification. CONTROLLING THE VISUAL INPUT

Original, masked, and inpainted views

Text printed on a meme is also present inside its pixels. The project considers multiple image views to explore how visible lettering and the underlying scene affect multimodal reasoning.

A

Original image

Preserve the complete meme, including overlaid text and the visual scene. The image and text branches may both encounter the same written content.

B

Masked image

Cover detected text regions while retaining the remaining pixels. This removes visible lettering but leaves explicit occlusions in the visual input.

C

Inpainted image

Reconstruct masked regions with Big-LaMa. The supplied excerpt shows qualitative comparisons between original images, text masks, and reconstructed scenes.

Inpainting changes the input and may introduce artifacts. The supplied examples demonstrate preprocessing behavior; they do not establish a measured gain in classification performance.

THE BENCHMARK BEHIND THE TASK

The Hateful Memes Challenge

The benchmark introduced by Kiela and colleagues tests whether a classifier can interpret an image and text together. Its benign confounders make reliance on a single modality unreliable: changing one part of a pair can change its meaning. HateReasoner builds on this multimodal problem setting.

EXPERIMENTAL DESIGN

Evaluating multimodal reasoning

The repository exposes image-view choices and multiple model variants. A controlled evaluation should isolate their contributions while keeping the split, training budget, and backbone fixed.

Evaluation axes and what each comparison can test. This is an evaluation guide, not a table of measured results.
ComparisonQuestionEvidence to report
Original / masked / inpaintedHow does overlaid text or reconstruction affect visual evidence?AUROC, F1, and accuracy on identical held-out examples
Context / semantic / graph pathwaysWhich components contribute beyond global image–text fusion?Controlled ablations with the same encoders and optimization
Global / local representationsDo patch–token relations capture information missed by global features?Matched architecture comparisons and qualitative error analysis
Confounder pairsDoes the prediction respond to changes in either modality?Paired examples, error categories, and calibrated confidence

For an unbiased final estimate, keep test data out of model selection. The current enhanced training entry point also evaluates on the test loader during training; revise that protocol before reporting final benchmark results.

Reproducing the research implementation
  1. Install the Python dependencies using the repository instructions and a PyTorch build suitable for your GPU.
  2. Prepare the local dataset and metadata for the selected image view. Check the loader’s expected paths and split names.
  3. For API-backed semantic guidance, provide credentials through environment variables and review which provider receives the inputs.
  4. Run the selected training entry point and retain configurations, seeds, checkpoints, and evaluation logs.
  5. Audit split separation and compare variants under matched settings before interpreting any improvement.

This is a research prototype. Context-sensitive moderation requires broader validation, error analysis across groups, and human review; a binary score alone is not a complete moderation decision.
